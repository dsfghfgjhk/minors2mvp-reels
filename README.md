# minors2mvp-reels

야구 게임 "2군에서 MVP까지"(minors2mvp.pages.dev) 홍보 릴스/스토리 제작 스크립트와 업로드 보드.

- scripts/make.py: 후원 장려 릴스 (픽셀 스타일)
- scripts/hit.py: 타격 힘 2배 릴스 (픽셀 임시본)
- scripts/story.py: 후원 감사 스토리 이미지
- scripts/fix*.py: 기존 릴스의 이름 바꾸기 (대화창/헤더 글자 교체)
- board/: 제목·캡션·해시태그 업로드 보드 (build.py → 릴스_업로드보드.html)

영상(mp4)은 용량 때문에 포함하지 않았습니다.
